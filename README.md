# 🎬 YouTube Clone (HTML + CSS)

A *YouTube homepage clone* built entirely using *HTML and CSS*.  
This project recreates the visual layout of YouTube’s homepage — including the navbar, sidebar, and video thumbnails — without using JavaScript or frameworks.

> ⚠ *Disclaimer:*  
> This project is made *only for educational and personal learning purposes*.  
> It is *not affiliated with or endorsed by Youtube* in any way.  
> All product data and images are placeholders and no real transactions occur.

---

## 🚀 Features

- 🧭 Fully responsive YouTube-like layout  
- 🎥 Video thumbnail grid with titles and channel details  
- 🔍 Top navigation bar with search box and icons  
- 📱 Sidebar with navigation links (Home, Explore, Subscriptions, etc.)  
- 🎨 Realistic YouTube color scheme and typography  
- 🖼 Custom YouTube favicon and logo  

---

## 🛠 Built With

- *HTML5* – for structure  
- *CSS3* – for styling and responsiveness  

No JavaScript, backend, or frameworks — just pure front-end design.
